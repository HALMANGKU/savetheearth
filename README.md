# 냠냠 지구 지킴이 🌍

초등학생이 급식 식판을 먹기 전·후로 기록하며 잔반을 스스로 줄이도록 돕는 학급용 웹앱의 안내 페이지입니다.

- **학생 화면**: 별명 + 비밀 숫자 4자리로 들어가 급식을 기록하고, 남긴 양의 이산화탄소·먹은 열량과 영양소를 봅니다.
- **선생님 화면**: 학급 현황 대시보드, 나이스 식단 연동, 식약처 표준데이터로 열량 자동 계산.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | GitHub Pages에 올리는 안내 페이지 (학생·선생님 들어가기 버튼, QR 코드) |

앱 본체(학생·교사 화면과 기록 저장)는 학교 구글 계정의 **Google Apps Script 웹 앱**에서 동작합니다.
`index.html`의 `APP_URL` 한 줄에 Apps Script 웹 앱 주소(`…/exec`)를 넣어 연결합니다.

## 개인정보

- 실명 대신 별명만 사용하고, 비밀 숫자는 암호화해 저장합니다.
- 사진은 저장하지 않습니다. 기록은 담당 교사의 학교 구글 스프레드시트에만 저장됩니다.
- 이 저장소에는 학생 정보가 없습니다.
